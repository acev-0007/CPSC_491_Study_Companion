# CPSC_491_Study_Companion

Study companion

The AI Study Companion is an interactive, web-based application that integrates a variety of AI-powered tools under one domain. Its primary goal is to assist students in transforming their study materials into dynamic and engaging resources. This application offers students key features such as automated flashcard and quiz generation, summaries based on their notes and readings, a free online textbook hub to access readings and study tools in one place, and visual image generation. Additionally, it includes an assignment and project tracker that allows students to plan and schedule their academic responsibilities, such as assignments and capstones, efficiently. With this tracker, students can schedule their day-to-day activities without any hassle, and the system ensures that students can meet their deadlines while maintaining a balanced workout. By automating these processes, the application allows students to focus more on comprehension and critical thinking rather than manual preparation. Each user can create a personal account, enabling the application to store individual progress, preferences, and access them anywhere at any time.

The core purpose of this AI Study Companion is to bridge the gap between artificial intelligence and practical education. Additionally, instead of using multiple applications to generate flashcards and other study tools, we developed a single application that can perform all these functions. Therefore, students can utilize this as a new mode of digital online tutoring.

This project aims to alleviate the stress and anxiety associated with ineffective time management. The assignment tracker ensures that tasks, projects, and deadlines are organized logically and completed efficiently. This not only enhances productivity but also encourages students to maintain a consistent study routine.

The development phase of this project consists of several key milestones. The initial phase includes requirements gathering, user interface design, and backend development for AI functionality. And the other phases focus on integrating machine learning models for summarization, flashcard creation, and image generation. The project also involves testing and user experience to improve the quality of this project. Ultimately, the goal is to deliver a fully functional, stable, and scalable platform that can be further expanded to support advanced features, like voice interaction, real-time tutoring, if we want to update this application in the future.

In summary, AI Study Companion represents an innovative approach to modern learning, combining artificial intelligence with practical educational support. It empowers students to take control of their learning process, improves organization and time management, and enhances academic performance through interactive and intelligent tools. As students, we understand what were the difficulties that we have been going through, and we strongly believe that the deployment of this application will be a useful tool for every student, because as education continues to evolve in the digital age, this project stands as a testament to how technology can be harnessed to make studying smarter, more engaging, and more efficient.
